# 🌑 Печальный Трекер Питания и Воды

Приватный анимированный трекер для безопасного похудения.

**Профиль:** 16 лет • 183 см • 119 → 75 кг • 2300–2400 ккал  
**Норма воды:** 2.5 литра  
**ИИ:** Печальная, заботливая, немного драматичная

### Особенности
- Строгая база еды (без рыбы, цитрусовых, сложной зелени)
- Расписание под график ГАПОУ ИНК (группа ЭС2-26)
- Динамические предупреждения (пропущенный завтрак, мало воды)
- Локальное хранение — всё только у тебя
