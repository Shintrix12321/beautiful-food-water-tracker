# 🌟 Beautiful Food & Water Tracker

Красивый анимированный трекер еды и воды с адаптацией через Google AI.

## Возможности
- 💧 Анимированный трекер стаканов воды
- 🍽️ Лог приёмов пищи с красивыми карточками
- 📊 Статистика за день / неделю
- 🤖 Готовность к интеграции с Google Gemini AI для персональных рекомендаций
- 💾 Всё хранится локально в браузере (приватно)
- ✨ Плавные анимации, glassmorphism, современный дизайн

## Как запустить
Просто открой `index.html` в браузере или задеплой на GitHub Pages / Netlify / Vercel.

## Google AI
В будущем можно добавить свой API-ключ Gemini в `script.js` для умных рекомендаций на основе того, что ты съел и сколько выпил воды.
