# Трекер Питания и Воды + Gemini

Приватный трекер для безопасного похудения с настоящим Google Gemini.

**Профиль:** 16 лет • 183 см • 119 → 75 кг • 2300–2400 ккал  
**Норма воды:** 2.5 литра  

### Главное
- Полноценный чат с **Google Gemini**
- Gemini **помнит** всё, что ты отмечал на сайте (еду, воду, вес)
- Строгая база продуктов (без рыбы, цитрусовых, сложной зелени)
- Расписание под колледж ГАПОУ ИНК

### Как подключить Gemini
1. Зайди на https://aistudio.google.com/apikey
2. Создай API-ключ
3. Вставь его в настройках сайта (кнопка ⚙️)

Всё хранится только в твоём браузере.
